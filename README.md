## Live Site
- **URL**: https://YOUR-SITE-URL/

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate on Scroll)**
- **EmailJS**
- **WebGL** (Fluid SplashCursor)

## Run Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/yashwindevadiga5-pixel/PortFolio.git
cd PortFolio
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Environment Variables

To enable contact form submissions via EmailJS, configure the following variables in a `.env.local` file:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
